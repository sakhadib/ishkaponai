The problem solver that shows its working.

Ask a physics, chemistry or maths question. ISHKAPON works it out step by step, in Bangla or English — and every number in the answer is genuinely calculated by a real Python interpreter running on your own computer. Not guessed. Not recalled.

A language model asked to do arithmetic in its head will sometimes invent a plausible-looking number. Asked to run 4.7 × 8.2 in Python, it cannot. That is the whole idea.

Install

Windows only, for now. Choose the file that matches your computer:

Download for Intel / AMD Windows Almost every Windows laptop and desktop. 143 MB · x64 Download for ARM Windows Snapdragon and other ARM laptops. 138 MB · arm64

Not sure which? Settings → System → About → System type. If it says “x64-based”, take the first one.

Then

  1. 1 Double-click the downloaded .msi and click Install. You do not need administrator rights.
  2. 2 Open ISHKAPON AI from your Start menu or desktop.
  3. 3 Go to Settings and paste your OpenRouter API key.

No API key? Choose Free Model in Settings instead. It works with no key and costs nothing.

Windows will show a warning. That is expected.

You will see “Windows protected your PC”, because the installer is not code-signed — no certificate has been bought yet, so Windows cannot confirm who published it. Click More info, then Run anyway.

This is not a malware warning, and ISHKAPON AI is not malware. It is what Windows shows for every program that has not paid for a signing certificate. If your school or office blocks unsigned installers, ask your IT administrator.

How it works

Most AI study tools ask a language model to produce an answer, arithmetic included. The model produces a plausible string of characters. ISHKAPON does not let it.

The model is only allowed to decide what to calculate. A real CPython interpreter — compiled to WebAssembly, running inside a locked-down sandbox — then performs the calculation, and the app shows you the code next to the result. If a number appears in an answer, Python produced it.

It cannot reach your computer

The sandbox has no network, no access to your files, and no ability to run programs on your machine. This is enforced rather than assumed: Pyodide is built for a browser and does not lock these down by itself, so each escape was demonstrated working and then closed. SymPy, NumPy and mpmath ship with the app, so a calculation never reaches the internet either.

Your chats stay yours

Everything is stored in a database on your own computer. There is no ISHKAPON account, no ISHKAPON server, and no analytics, telemetry or crash reporting of any kind.

Bangla or English

Answers come in whichever language you choose. Numbers, units and equations stay in Latin script either way, because Bangla digits and symbols cannot be typeset inside a physics formula.

Bring your own model

Use any model on OpenRouter, or their free router. Change it whenever you like in Settings.

Please read this part

A language model is sometimes wrong, and it is wrong confidently. ISHKAPON verifies the arithmetic, because the arithmetic is actually run. It cannot check that the model set up the right calculation for your question in the first place.

So treat it as a second opinion and a study aid — not as an answer key. For an exam, a submission or a lab conclusion, check the answer against your textbook or your teacher. The terms say this plainly too.

Other platforms

The code is cross-platform and macOS and Linux builds are configured, but the installers do not exist yet. They were not produced by the machine that built this release, and shipping a build nobody has run would be worse than not shipping it.

They are being built on Linux and macOS runners and will be added to a later release. Nothing is wrong with the app on those platforms — the artefacts simply do not exist yet.

Your data

Your question, and the conversation needed to answer it, are sent to OpenRouter — that is the only network traffic the app generates, and a language model has to run somewhere for an answer to come back.

If you fill in your name, age, grade or subjects in Settings, those are sent too, with every question. They are entirely optional and the app is fully usable with all of them blank. A nickname rather than a full name limits this.

Your API key is encrypted with your operating system's secret store. Uninstalling does not delete your chats; they live in %APPDATA%\ISHKAPON AI\ishkapon.db, and deleting that file erases them.

The privacy policy has the full detail, with the source file behind every claim.

Contributing

ISHKAPON is open source under the MIT licence, and contributions are genuinely welcome — bug reports, translations, better explanations, or code.

It is built with Electron, React and TypeScript. If you want to work on it, you need Node 22 or newer: 

git clone https://github.com/sakhadib/ishkaponai.git
cd ishkaponai
npm install
npm run dev

Two things will help you find your way. The README explains the architecture, and decisions.md records why things are the way they are — including the decisions that were tried and then reversed, which is usually the part you cannot guess.
